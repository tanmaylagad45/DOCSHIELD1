# DocShield — Frontend Application

This directory contains the React + Vite + TypeScript + Tailwind CSS frontend for **DocShield**, featuring:
- An interactive 3D SaaS Landing Page powered by Three.js and React Three Fiber
- Accessible SVG/CSS visualizer fallback for non-WebGL or reduced-motion environments
- Complete verification workspace with light and dark theme persistence
- Modular route architecture for Dashboard, Document Ingestion, Manual Cases, Compliance Rules, Reports, and Audit Trail

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4
- **3D Graphics**: Three.js + React Three Fiber + Drei
- **Routing**: React Router DOM
- **Icons**: Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run production build validation
npm run build
```
